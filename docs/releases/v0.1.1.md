# markText v0.1.1

- Support editing two notes side by side with the existing visual editor. Use the note tab context menu to open or close the split.
- Watch multiple root folders in one window and search across them. Add folders from the file tree context menu.
- Restore file creation, rename, copy, cut, paste, trash, path copy and reveal operations directly in the file tree context menu. Remove the standalone repository manager.
- Move files and folders in the tree, including files dragged in from the system file manager.
- Show non-Markdown file types and open them with the system-associated application.
- Move outline headings together with their body and subordinate sections in visual editing mode.
- Serialize Mermaid rendering to avoid shared configuration conflicts between concurrent diagrams.
- Synchronize title bar preferences across windows; native window frames apply when a new window is created.
